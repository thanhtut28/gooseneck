# GooseNeck 1.0.5 — fix Activate License button

A targeted fix for the new Activate License button in Settings.

## What's fixed

In v1.0.4, clicking **Activate License** in Settings → License & About did nothing. The button now correctly opens the activation flow, matching the existing Deactivate path.

That's it. If you're already on v1.0.4 with Sparkle started, this update will install via the in-app updater the next time you click Check for Updates (or automatically, if you have automatic checks enabled).

## Compatibility

- macOS 14 Sonoma or later
- Apple Silicon Mac (M1 or newer)
