# GooseNeck

Real-time posture and ergonomic coach for Apple Silicon MacBooks. A menu-bar app that uses built-in hardware sensors (accelerometer + lid angle) to monitor posture drift, track breaks, and detect typing fatigue — no webcam, no cloud, fully local.

**Requirements:** macOS 14 Sonoma or later, Apple Silicon (M1+).

## Download

Get the latest signed and notarized DMG from the [Releases](https://github.com/thanhtut28/gooseneck/releases) page.

## Auto-updates

The app checks for updates automatically via Sparkle.
